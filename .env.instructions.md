# Environment Variables Setup Instructions

## OpenAI API Key Configuration

1. **Create .env file** (if not already created):
   ```bash
   cp .env.example .env
   ```

2. **Add your OpenAI API key** to the .env file:
   ```
   VITE_AI_API_KEY=sk-your-actual-api-key-here
   ```

3. **IMPORTANT: Restart the development server**:
   - Stop the current server (Ctrl+C)
   - Start it again: `npm run dev`

## Troubleshooting

If the API key is still not working:

1. **Check the .env file format**:
   - No quotes around the API key
   - No spaces around the equals sign
   - The key should start with `sk-`

2. **Verify the key is loaded**:
   - Open browser console
   - Look for "AI Service initialized" log
   - It should show `hasApiKey: true` and the key length

3. **Clear Vite cache** (if needed):
   ```bash
   rm -rf node_modules/.vite
   npm run dev
   ```

4. **Make sure you're using the correct environment variable name**:
   - Must be prefixed with `VITE_` for Vite to expose it to the client
   - Exact name: `VITE_AI_API_KEY`

## Note on Security

- Never commit the .env file to git (it's already in .gitignore)
- The API key will be visible in the browser, so use a key with limited permissions
- Consider implementing a backend proxy for production use
